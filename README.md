# Hisap Kitap

Hisap Kitap is a Flutter shop ledger and billing app for small businesses.
It helps shop owners track stock, sales, investments, customer dues, payments,
invoices, and daily reports from one app.

## Features

- Product stock-in and sale-out entries
- Investment and expense tracking
- Customer ledger with credit and payment records
- Cash, card, and UPI payment method tracking
- Invoice creation, PDF printing, and WhatsApp sharing
- UPI QR code support
- Low-stock alerts
- Daily and monthly reports
- Local data storage with SharedPreferences
- Multi-language labels for English, Assamese, Turkish, and Hindi

## Platforms

- Android
- Web
- Desktop targets generated by Flutter, if enabled locally

## Requirements

- Flutter 3.41.9 or newer
- Dart 3.11.5 or newer
- Android SDK for Android builds

## Build

Get dependencies:

```sh
flutter pub get
```

Run on Chrome:

```sh
flutter run -d chrome
```

Build Android APK:

```sh
flutter build apk --release
```

Build web:

```sh
flutter build web --release
```

## F-Droid

This project is intended to be publishable on F-Droid. F-Droid builds apps from
